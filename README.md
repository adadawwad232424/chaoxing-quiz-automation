# 📚 超星学习通章节测验自动化脚本 (Chaoxing Quiz Automation)

这是一个基于 Tampermonkey（篡改猴）的超星学习通章节测验提取与自动答题工具。针对超星不同的课程排版，本项目提供**两款**脚本，配合 AI 即可实现全自动提取与作答。

## ✨ 特性
- 🚀 **全自动遍历**：无需手动点开每一节，自动遍历侧边栏所有测验节点。
- 🧠 **AI 协同**：提取干净的题目格式，配合专属 Prompt 让 AI 返回精准的 JSON 答案。
- 🛡️ **防抖与智能点击**：兼容最新的网页 DOM 结构，防误触，自动处理确认弹窗。

## 📥 一、 安装指南

### 第一步：安装篡改猴（Tampermonkey）
你的浏览器必须先安装“篡改猴”插件才能运行本脚本。
- **Chrome / Edge 用户**：如果无法访问官方应用商店，可以使用镜像站安装：[点击这里前往安装 (Chrome版)](https://www.crxsoso.com/webstore/detail/dhdgffkkebhmkfjojejmpbldmpobfkfo)
- **Firefox / 其他浏览器**：可以访问上述镜像站首页搜索“Tampermonkey”，或前往浏览器自带的扩展商店搜索安装。

### ⚠️ 第二步：开启“允许用户脚本”权限（非常重要）
新版 Chrome/Edge 浏览器安装篡改猴后，默认是关闭脚本权限的，**如果不开启，脚本会无法运行！**
1. 点击浏览器右上角的扩展图标（拼图图标），找到篡改猴。
2. 右键点击篡改猴，选择 **“管理扩展程序”**（或进入浏览器的扩展管理页面）。
3. 找到 **“允许用户脚本” (Allow User Scripts)** 或 **“开发者模式” (Developer mode)**，将其**打开**。

### 第三步：安装本项目的脚本
根据你的课程类型，点击安装对应的脚本：

| 课程类型 | 脚本名称 | 一键安装链接 |
| :--- | :--- | :--- |
| **每小节都有测验** (如每节都有独立测验) | 小节版 (V2.5) | [点击安装](https://raw.githubusercontent.com/adadawwad232424/chaoxing-quiz-automation/main/chaoxing-quiz-scraper.user.js) |
| **章末单节点测验** (如1.6才是测验) | 章末版 (V3.1) | [点击安装](https://raw.githubusercontent.com/adadawwad232424/chaoxing-quiz-automation/main/universal-chapter-answer.user.js) |

> **💡 兜底方案：如果点击“一键安装链接”没反应怎么办？**
> 如果网络原因导致链接无法唤起篡改猴，你可以：
> 1. 在 GitHub 仓库中点击下载对应的 `.user.js` 文件到电脑本地。
> 2. 点击浏览器右上角的篡改猴图标，选择 **“添加新脚本”**。
> 3. 把下载下来的文件内容用记事本打开，全部复制，粘贴到篡改猴的编辑器里，按 `Ctrl+S` 保存。
> 4. 或者把 `.user.js` 文件直接拖拽到浏览器窗口，篡改猴也会自动识别。

## 🛠️ 二、 使用教程

### 第一步：提取题目
打开超星课程页面，右侧会出现绿色的控制面板。点击 **“1. 提取题目”**，脚本会自动遍历所有章节并将题目提取到左侧文本框中。

### 第二步：让 AI 生成答案
复制左侧框里的所有文本，并使用下方的专属提示词发送给 AI（如 ChatGPT / Claude / 文心一言等）：

<details>
<summary>👉 点击展开：小节版 (V2.5) AI 提示词</summary>

```text
你现在是一个超星学习通的答题助手。我接下来会给你发送提取出来的题目和选项。
请你根据题目内容，直接给出正确选项的字母（单选输出1个字母，多选输出连续字母，判断题输出 true 或 false）。
必须严格按照以下 JSON 格式输出，Key 必须是【】中的章节名称（忽略开头的数字序号）：
{
  "食品、特殊食品的概念": ["D", "B", "ABC"]
}
以下是提取的题目：
```
</details>

<details>
<summary>👉 点击展开：章末版 (V3.1) AI 提示词</summary>

```text
你现在是一个超星学习通的答题助手。我接下来会给你发送提取出来的题目、选项以及章节的 chapterId。
请你根据题目内容，直接给出正确选项的字母（单选输出1个字母，多选输出连续字母，判断题输出 true 或 false）。
必须严格按照以下 JSON 格式输出，Key 必须是题目开头括号里的 chapterId（纯数字）：
{
  "1267275427": ["A", "AB", "true"]
}
以下是提取的题目：
```
</details>

### 第三步：自动答题
将 AI 返回的 JSON 代码（包括大括号 `{}`）复制。

粘贴到右侧蓝色的 **“AI 答案注入 (JSON)”** 框中。

点击 **“2. 开始自动答题”**，脚本将自动切换章节、勾选选项并提交。
